Title: Project Feedback

Haichuan's feedback: Before you solve any specific algorithmic problem, you probably need to have a model and a corresponding optimization problem first. I haven't looked into the literature, but it would be interesting to see whether there is any good benchmark for modeling capability, as such evaluation is partially subjective and hard to evaluate. Some optimization problems are hard to solve and may go beyond current LLM's capability (at least in one shot), so you might need to design a good workflow to handle model hallucinations and failures. An easier way to alleviate the previous challenges is to focus on RL approaches because it's easier to define MDP than an arbitrary model, and that makes the algorithmic selection also easier (pick among popular RL algorithms).
