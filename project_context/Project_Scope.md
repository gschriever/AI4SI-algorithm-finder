Project name: AI4SI Algorithm Finder

Team members: Hyungsik Kim, Gillian Schriever, Ingrid Chien

Objective: To develop a chatbot that identifies the right algorithms for a given specific social challenge. With this project, the project aims to:

Map out the AI4SI space by bridging the social problem space with available AI/ML techniques
Support social problem solvers to use the right AI/ML techniques

Approach: The project will be conducted in four phases

Space mapping: Map out key dimensions in the two areas:
Social problem space (e.g., # of stakeholders, duration, defined objectives)
AI/ML techniques (e.g., # model function, parameter types, defined output)
Framework definition: Define the AI4SI framework by connecting the two dimensions
Chatbot building: Develop an LLM chatbot that can answer questions based on the framework
4.      Model evaluation: Evaluate the model based on testing the model effectiveness based on the social problems context identified in the past AI4SI papers without sharing the techniques used
