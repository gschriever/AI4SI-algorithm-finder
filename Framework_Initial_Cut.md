Layer 1: Understanding social problems 

Nature of constraints (resource based)

Adaptive (undefined end state OR undefined activities) → System-definition (AI can assist / support)
Alignment - Problem / agenda / action
Coalitions/coordination - Stakeholder coalitions / factions / coordination
Power - Value-driven interrelations
Inertia - Emotions, work avoidance, adaptive capacity
Adaptive incentives (qualitative) - Benefits, loss 
Institution - Rules and standards
FOCUS: Technical (defined end state, defined activities) → System-optimisation (AI can solve)
Resource misallocation - imbalance
Resources scarcity - Money, capacity/time
Information flow - Awareness, info distribution, asymmetry
Unknown - Hidden info, uncertainty
Technical incentives (quantitative)
Scale - complexity, scalability
